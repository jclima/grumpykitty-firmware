GrumpyKitty Web Flasher

Install the GrumpyKitty firmware on an ESP32-S3 (N16R8) MeowKit-S3 device, straight from your browser.

This browser cannot flash devices. Web Serial is needed: use desktop Chrome or Edge (not Safari, Firefox or a phone browser).
Use desktop Chrome or Edge to flash. Web Serial needs a secure (HTTPS) page.

Put the device in Download Mode first (below), then click Install and pick the USB JTAG/serial debug unit port.

1. Before you start

  • Desktop Chrome or Edge (Web Serial). Safari and Firefox do not work.
  • A USB-C data cable (some cables are charge-only), plugged directly into the computer, no hub.
  • A Dupont jumper wire (or a straightened paper clip) to reach the BOOT button.
  • Flashing never touches the SD card.

2. Enter Download Mode

  1. Power the device off.
  2. Push the jumper wire through the small hole on the back and keep BOOT pressed.
  3. While holding BOOT, press and hold Power for 1-2 seconds.
  4. Release Power, then release BOOT. The screen stays off; that is correct.
  5. Connect the USB-C cable to the computer.

3. Flash

  1. Click Install above.
  2. Choose the port named USB JTAG/serial debug unit and click Connect.
  3. Answer the Erase device? question (see below), then confirm. Do not unplug until it says finished (about a minute).
Erase device?
  • Leave it unticked when updating from a GrumpyKitty build. Your settings are kept. (Updating from stock MeowKit firmware has not been tested; tick it if unsure.)
  • Tick it for a clean start or if the device misbehaves after an update. Erasing wipes saved settings (including Wi-Fi). It never touches the SD card.

4. After flashing

  1. Hold Power for 4-5 seconds to power the device off.
  2. Press Power to boot. (Alternatively, briefly short RESET to GND.)

Port does not appear?

  • Try another USB-C cable: it must carry data.
  • Plug directly into the computer, no hub or dock.
  • Repeat Download Mode: unplug, power off, redo the BOOT + Power sequence, then reconnect.
  • Close any serial monitor, PlatformIO or other app that may hold the port.
  • On Linux, your user may need to be in the dialout group.
