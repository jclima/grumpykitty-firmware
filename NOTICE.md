## (e) GPL warning for firmware binaries

Distributing a firmware binary that links GPL-3.0 libraries generally triggers GPL obligations (offering corresponding source and the license text, and compatible terms for the combined work). In `src/`, a check with `grep -rn "audio.h\|Audio.h\|arduinoFFT\|FFT.h" src` finds:

- `ESP32-audioI2S` **is** used: `src/bsp/devices.cpp` includes `<Audio.h>`, and `src/system/system_sound.cpp` includes `lib/ESP32-audioI2S/src/mp3_decoder/mp3_decoder.h`. The PlatformIO build map shows `libESP32-audioI2S.a(mp3_decoder.cpp.o)` is linked into the firmware.
- `arduinoFFT` is **not** included anywhere in `src/` and no `arduinoFFT` symbols appear in the build map.

Whether a given build is distributable under your intended terms depends on these facts; get legal advice before releasing binaries. `IRremoteESP8266` (LGPL-2.1) code is also linked and brings its own obligations (for example, allowing relinking). Upstream's own unlicensed code compounds the uncertainty.
